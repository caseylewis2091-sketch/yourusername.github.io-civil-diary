# Civil Diary v2

A phone/laptop-friendly project-based prototype.

## What is included
- Projects as the top level
- Project dashboard
- Daily diary
- Photos & records
- Tasks / to-do
- Installable PWA shell
- Offline caching
- Data saved locally in the browser

## Important
This is still a prototype. Local browser storage is NOT suitable as the permanent record for live construction work. It does not yet sync between phone and laptop and photos are stored locally.

## Next production step
Connect the UI to a hosted database/storage service and authentication. Then add:
- phone/laptop cloud sync
- proper photo storage
- voice notes
- AI diary generation
- TQs/RFIs
- setting-out/as-built records
- drawings/documents
- PDF reports
- backups/export
